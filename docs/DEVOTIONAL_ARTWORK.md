# Devotional artwork

Three original transparent PNG illustrations were generated using the built-in ImageGen tool for use as movable image elements in WishFest. They are bundled with the app, require no network connection, and use the existing image-layer serialization and rendering for saved cards and exports.

Assets:
- `app/src/main/assets/devotional/lakshmi.png`
- `app/src/main/assets/devotional/ganesh.png`
- `app/src/main/assets/devotional/kali.png`

Access: Editor → Elements → Devotional images. Tap an illustration, then drag it on the canvas to move it. Drag the gold corner handle to resize it while preserving its proportions, or use the image size and rotation sliders at the top of Elements. Tapping an image on the canvas opens its controls. Duplicate and remove controls are available for the selected image; Undo restores previous edits.
